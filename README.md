# EXCARRA Admin : mises à jour

Ce dépôt sert uniquement à distribuer les mises à jour du logiciel Windows EXCARRA Admin.
Il contient l'installateur de la dernière version, son `.blockmap` et `latest.yml`.
Aucun code source, mot de passe ni clé. Le logiciel ne donne accès à rien sans un compte administrateur EXCARRA.
